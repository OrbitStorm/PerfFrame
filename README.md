# PerfFrame

PerfFrame is a lightweight, modern performance display that shows your FPS and network latency at a glance; replacing the need to hover over the default UI with a clean, movable frame that stays visible when you need it most.

### Features
* Real-time FPS and latency display
* Clean, movable frame (ALT + drag)
* Optional tooltip to display addon memory usage with configurable display limits
* Optional combat toggles to display the frame in or out of combat
* Adjustable text scale for better readability
* Opacity slider for the frame background
* Customizable label colors (class-colored labels, single color, or separate FPS / MS colors)
* Per-character or global frame positioning
* Persistent frame position between sessions
* Intuitive settings panel for easy configuration
* Lightweight and unobtrusive design
* Compatible with Retail, Classic Era, Burning Crusade Classic, and Mists of Pandaria Classic


### Moving PerfFrame
Hold ALT + left-click and drag. It's that simple!


### Accessibility
PerfFrame includes a highly-customizable text-scale and opacity options to improve visibility on any display.

### Manual Installation
* Extract the PerfFrame folder into the correct client folder (for example):  
`World of Warcraft/_retail_/Interface/AddOns/`
* Enable PerfFrame in the AddOns menu if it isn't already.
* Type `/pf help` in-game for a list of available commands.


### Quick Installation
Use CurseForge's desktop app, found here: [Download CurseForge App - Mods, Addons and CC Manager](https://www.curseforge.com/download/app)

PerfFrame is designed to be compatible with all Retail/Classic clients.


### Credits
PerfFrame began as a modern rewrite inspired by [FPS-MS-Tracker](https://www.curseforge.com/wow/addons/fps-ms-tracker) during a period when that project was no longer actively maintained.
